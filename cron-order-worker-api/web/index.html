Cron Order Worker API Demo

Test health, orders, cron job listing, manual job execution, and job history from one page.

GET /health

Health Check

Checks whether the API server is running.

GET /api/v1/orders

List Orders

Shows demo orders and their sync status.

POST /api/v1/orders/seed

Seed Orders

Creates demo failed and pending orders.

GET /api/v1/jobs

List Jobs

Displays all registered cron jobs.

POST /api/v1/jobs/retry_failed_orders/run

Run Retry Job

Manually triggers the failed order retry job.

GET /api/v1/jobs/history

Job History

Shows recent cron/manual job execution history.

Click any API button to see the response here.
